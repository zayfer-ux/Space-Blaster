# 🚀 Space Blaster

¡Bienvenido a **Space Blaster**! Un videojuego arcade en 2D desarrollado con Python y Pygame. Defiende tu sector espacial controlando a un valiente cubo azul, esquivando y destruyendo a los incesantes invasores rojos antes de que agoten tus defensas. 

🚧 **Estado del Proyecto:** *Work In Progress (WIP)*. El juego es completamente funcional, pero el motor de propulsión sigue en el taller. ¡Nuevas mecánicas y mejoras visuales están en camino!

## 👾 Dinámica de Juego
* **El Héroe:** Controlas un cubo azul de alta velocidad equipado con cañones de energía[cite: 3].
* **La Amenaza:** Enjambres de bloques enemigos rojos descienden implacablemente desde la parte superior de la pantalla[cite: 2, 4].
* **El Arsenal:** Dispara ráfagas de plasma celeste (`#8DE8F2`) para desintegrar a las naves enemigas[cite: 1].
* **Supervivencia:** Tienes 5 vidas al iniciar[cite: 4]. Si un enemigo choca contra ti, pierdes una vida[cite: 4]. Si los enemigos logran cruzar el borde inferior de la pantalla, acumulas puntos[cite: 4].

## ⚙️ Controles
* `A` - Moverse hacia la izquierda[cite: 4]
* `D` - Moverse hacia la derecha[cite: 4]
* `ESPACIO` - Disparar[cite: 4]

## 🛠️ Instalación y Ejecución
Para probar la versión actual en tu propia máquina:
1. Asegúrate de tener Python instalado.
2. Instala la librería Pygame: `pip install pygame`
3. Ejecuta el archivo principal: `python "space blaster.py"`
